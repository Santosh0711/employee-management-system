# Employee Management System

A full-stack Employee Management System built using **Java Spring Boot, MySQL, and React**.

## Features

- Add new employees
- View all employees
- View employee by ID
- Update employee details
- Delete employees
- Search employees by ID, name, or email
- Sort employees by ID, name, age, and salary
- Pagination
- Dashboard with employee statistics
- Client-side form validation
- Backend validation
- Global exception handling
- REST API
- Swagger / OpenAPI documentation
- Unit testing
- Controller/API testing
- Responsive user interface

## Technologies Used

### Backend

- Java 21
- Spring Boot
- Spring Web
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Jakarta Validation
- Swagger / OpenAPI
- JUnit
- Mockito
- MockMvc

### Frontend

- React
- JavaScript
- Vite
- HTML
- CSS

### Database

- MySQL 8
